# Contributing

The project is at the planning stage. Please open an issue to discuss substantial changes before starting work.

## Pull requests

1. Fork the repository and branch from `feat/relai-agent-inbox`, the current product work branch. Target that branch for changes to the new inbox until it is integrated into `main`.
2. Keep each pull request focused on one topic.
3. Run `make check` before you push. See the README for the other `make` targets.
4. Open a pull request and explain what changed and how you checked it.

The maintainer, [@boussecsou](https://github.com/boussecsou), reviews and merges every pull request. `main` is protected: changes land through a reviewed pull request that passes CI, and are squash-merged.

## Ground rules

- Keep credentials, private messages, and personal data out of commits, issues, and test fixtures.
- Report vulnerabilities privately using [SECURITY.md](SECURITY.md), never in a public issue or pull request.
