# Security policy

## Supported versions

The project has no released software yet. Security reports about this repository are still welcome.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** option in the repository's Security tab to send a private report to the maintainer. Do not open a public issue or pull request for a vulnerability.

Include a description, reproduction steps, potential impact, and a suggested fix if available. Do not include real credentials, private messages, or personal data in the report.
