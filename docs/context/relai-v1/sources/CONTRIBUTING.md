# Contributing

The project is at the planning stage. Please open an issue to discuss substantial changes before starting work.

For code contributions, use a pull request and explain what changed and how you checked it. Keep credentials, private messages, and personal data out of commits, issues, and test fixtures. Report vulnerabilities privately using [SECURITY.md](SECURITY.md).
