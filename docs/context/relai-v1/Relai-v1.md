## Maquettes et conservation

[Interface principale](assets/relai-design/index.html) ; [galerie terminaux](assets/relai-design/terminal-concepts/index.html).

Les dossiers assets et sources conservent intégralement le workspace design et les documents du dépôt, y compris versions historiques, recherches brutes, captures, sources de construction, licences et preuves. Le journal UX original et le changelog complet restent la référence détaillée de chaque modification. Les nouveaux réglages sont documentés comme propositions ; aucun contrôle d’agent réel n’a été ajouté.

## Usage

Ouvrir les HTML localement sans dépendance. Importer Markdown et CSV dans Notion suivant le guide ; les corps de pages, fichiers et relations ne se relient pas automatiquement par CSV. Les chemins relatifs fonctionnent dans cette archive et devront être adaptés dans Notion.

La consolidation conserve les décisions connues de cette conversation et tous les fichiers disponibles ; elle n’invente pas de transcript intégral du chat ni de publication distante.
