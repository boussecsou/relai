# Relai — terminal integration concepts

Open index.html to explore three separate interactive HTML concepts:

1. 01-session-workspace.html — session panel, activity, output, resume and permission examples.
2. 02-agent-profiles.html — inherited native configuration, skills and compatibility states.
3. 03-session-connections.html — connected, saved, reachable-server and unknown external sessions.

Each HTML file embeds its CSS, JavaScript, IBM Plex font and Lucide icons. No installation is required. Keep the four HTML files together to follow their navigation links. Open the ZIP bundle after extraction for the complete set.

Light/dark preferences are stored locally when browser storage is available. All agent connections, versions, commands, permissions and configuration files are examples. No agent process or network connection is created by these pages.

TERMINAL-INTEGRATION.md contains the French architecture study and source references. UX-DECISIONS.md records the UI decisions. validation.json records the executed browser checks. research/sources.json distinguishes successful source reads from missing paths. These are research/UI artifacts, not production integrations.

Licenses for embedded assets are included under licenses/.
