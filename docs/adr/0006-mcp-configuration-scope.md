# Définir la portée de la configuration MCP

Statut : proposé.

Ajouter un MCP peut signifier que Relai consomme un serveur, configure un outil natif ou expose ses propres données. Ces options changent le propriétaire de configuration, les permissions et les intégrations. Définir consommateur, portée projet/machine/agent/session et effet sur les sessions actives avant de choisir une option.

Aucun parcours MCP n’est implémenté dans le prototype ; les permissions et skills observés ne constituent pas une configuration MCP.
