# Définir les événements de retour dans l’inbox

Statut : proposé ; règle de base retenue, politique complète ouverte.

Une nouvelle réponse actualise le fil existant, devient identifiable/non lue et remonte dans la liste. La simulation remet le fil dans l’inbox, même après traitement/report. Il reste à définir ce qui constitue une nouvelle réponse, le traitement des doublons et progressions, les reports, la conservation des décisions antérieures et les revues récurrentes inchangées.

Comparer chaque événement, seulement les réponses finales et les changements significatifs. La simulation d’un événement ne constitue pas une décision complète pour le futur système de collecte.
