# Une interface dans le navigateur

Relai utilisera une interface navigateur pour son premier parcours utilisateur. L’utilisateur souhaite une application graphique locale et veut pouvoir ouvrir plusieurs onglets ; ce choix permet de travailler sur l’inbox sans imposer un package desktop. Le rôle de Docker et la connexion aux harnesses du poste restent à définir séparément.
